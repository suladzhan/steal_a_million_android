`Tools/Review-InUnity.ps1` копирует экспорты в отдельный `.utmp/asset-review`, проверяет импорт FBX в Unity 6000.3.23f1 и собирает preview-prefabs, материалы, 38 ограниченных по частицам VFX-пресетов и 10 шаблонов UI-анимаций. Факт успешного выполнения определяется по `Reviews/Unity__v001__report.json` и `PRODUCTION_REVIEW_PASS` в логе, а не по наличию этого скрипта.

Пакет при успешной проверке: `04_Exports/SAM_ArtPilot__v001.unitypackage`. Его не импортировали в игровую ветку. Runtime, сцены, экономика, save ID и текущие игровые prefabs не изменялись.

UI-анимации — подключаемые шаблоны: `UIA_tab` предполагает дочерний `Marker`, unlock — `Lock`/`Check` с CanvasGroup; progress анимирует Image.fillAmount. До привязки заменить конечное значение progress/позицию маркера фактическим значением состояния. Не ставить clip 0→1 на реальный прогресс без такого адаптера. Эти шаблоны не реализуют очередь toast или lifecycle игры.

VFX стартуют программным `Play`, без игровых событий в animation/particle callbacks. Runtime должен подавать семантический цвет ворот и отрицательной delta, соблюдать общий пул/cap и останавливать loop-эффекты по состоянию. Текущий пакет не подключает их к игровым событиям.
