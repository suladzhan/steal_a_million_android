# Производство ассетов STEAL A MILLION V2

Рабочая папка этапа 05: арт-направление, генерация, проверка и подготовка ассетов для существующего Unity-проекта.

Документация составляется по `version 2.md`, текущему коду и каталогам игры. Промпты предназначены для Grok, Meshy и обработки в Blender; готовность модели не равна готовности к импорту.

Пока производство не прошло проверку, текущие процедурные модели остаются рабочим резервным вариантом. Исходники и результаты генераций хранятся здесь, вне `Assets`, чтобы Unity не импортировала их автоматически.
